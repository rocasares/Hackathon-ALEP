# Landing

Página de presentación de ATLAS NEX. **No es una ruta de la aplicación**: es una
página autocontenida para pegar en la submission y para compartir.

Se dejó fuera del router a propósito. Si viviera en `/`, quien corre `npm run dev`
vería marketing antes que la herramienta, y con seis minutos de atención eso
juega en contra. La aplicación se abre en `/` y hace su trabajo.

Tiene un segundo uso: **es el guión visual del video**. Los mismos planos, en el
mismo orden — el corte de red, el problema, cómo funciona, la evidencia y los
modos de falla.

Publicada como artifact:
https://claude.ai/code/artifact/f1f2c411-e794-4bee-a605-e9128d8dcae9

Para verla localmente basta abrir `index.html` en el navegador: no tiene build ni
dependencias, sólo las fuentes de Google.
